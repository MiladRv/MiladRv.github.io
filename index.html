ASP.NET Core middleware that offloads synchronous controller actions to background threads and returns an instant trackId for client polling. Supports .NET 8 and 10, published on NuGet. Originally built as part of a team project; forked and continued independently after the upstream repository was archived, adding support for newer .NET versions and maintaining the package.
